How the pipeline works

Everything runs locally. Job descriptions go to your chosen LLM; your files stay on this machine.

  1. Discover — python jobhunt.py run searches Naukri/Indeed, dedupes and scores jobs. Or python jobhunt.py discover then score.
  2. Review — this dashboard shows score, reason, red flags and salary fit. Shortlist the good ones.
  3. Prepare — click Prepare (or python jobhunt.py prepare <id>) to generate a tailored PDF/DOCX resume, cover letter and screening answers. Nothing is invented: bullets and skills are validated against data/master_resume.yaml.
  4. Autofill — click Autofill. A browser opens with your persistent login profile, fills known fields, uploads the resume and pastes answers. It never clicks Submit.
  5. Submit & track — review the form, hit Submit yourself, then set status to Applied. Use the status dropdown as your source of truth.

First run? Edit config.yaml and data/master_resume.yaml, put GEMINI_API_KEY in .env, then run python jobhunt.py doctor.
